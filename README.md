# C++ Tutorial for Complete Beginners

Standalone C++ exercises covering variables, control flow, arrays, functions, pointers, classes, and inheritance. These are course practice programs, not a single application.

## Getting started

Compile one exercise at a time, for example `g++ -std=c++11 04_hello_world.cpp -o hello` and then `./hello`. Some later exercises reference course headers that are not included in the repository.
